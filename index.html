SVMs, visually

Of all the lines that separate two classes, take the one farthest from every sample.

How far is a sample from the line?

Goal: the SVM picks the line farthest from every sample, so first we need the distance, or margin, from a point x to the line w·x + b = 0.

Approach: six steps, from the line to the margin of any point (the panel beside the plot). Each step leans on the one before.

margin(x) = w·x + b‖w‖ ⇒ with ‖w‖ = 1:  w·x + b

Labels are now y ∈ {−1, +1} and ŷ = sign(w·x + b). A sample is on its own class's side exactly when y(w·x + b) > 0.

Hard margin: the widest street

Goal: many lines separate the classes. Pick the one whose nearest sample is farthest away.

Approach: rescale w and b so the nearest sample has y(w·x + b) = 1. The margin is then 1/‖w‖, so the widest street has the shortest w (Boser, Guyon & Vapnik 1992):

min 12 ‖w‖2  subject to  yi(w·xi + b) ≥ 1 for every i

With Lagrange multipliers (lesson 15's λ, written αi for the SVM): w = ∑ αiyixi and ∑ αiyi = 0, with αi ≥ 0, and αi = 0 unless the constraint is active, yi(w·xi + b) = 1. The samples with active constraints sit on the street's edge: the support vectors.

Soft margin: pay for slack

Goal: when the classes overlap, no line meets every constraint. Let sample i fall short by its slack ξi ≥ 0, at a price of C per unit (Cortes & Vapnik 1995).

min 12 ‖w‖2 + C ∑ ξi  subject to  yi(w·xi + b) ≥ 1 − ξi,   ξi ≥ 0

A stick runs from each sample with slack to its own class's margin line; its length is ξi/‖w‖. The multipliers are now capped, 0 ≤ αi ≤ C, and every sample with slack has αi = C.

Try this

  • In step 1, drag the tip of w to make it twice as long. Does the line change?
    AnswerYes, unless b doubles too: (2w)·x + b = 0 is the line w·x + b/2 = 0, half as far from the origin. Scaling w and b together leaves the line alone, which is why step 3 may assume ‖w‖ = 1.
  • In step 2, point w straight up, at [0, 1]. Which line is it?
    AnswerThe horizontal line x₁ = −b: slope −0/1 = 0. Every vector along it is [t, 0], and [t, 0]·[0, 1] = 0.
  • In step 6, drag x parallel to the line, then across it. When does the margin change, and when is it negative?
    AnswerMoving parallel to the line leaves w·x (and the margin) alone; only motion along w changes it. It is 0 on the line and negative on the side w points away from.
  • Drag a sample that is not a support vector, staying off the street. Does the line move?
    AnswerNo. Its constraint is inactive, so its α = 0 and it is not in w = ∑ αiyixi. Only the samples on the street's edge shape the line.
  • Drag a support vector toward the other class.
    AnswerThe street narrows: ‖w‖ grows, so 1/‖w‖ shrinks, and the αs grow. Past the other class's samples there is no separating line at all.
  • In the support vectors table, why are there support vectors from both classes?
    Answer∑ αiyi = 0 with every αi > 0 needs some yi = +1 and some −1. Geometrically: the street has an edge on each side.
  • Slide C from 0.01 to 1000. What happens to the margin and the number of support vectors? Compare the sweep over C.
    AnswerSmall C: slack is cheap, so a wide street with many samples inside the margin (all support vectors). Large C: slack is expensive, so the street narrows to push samples out, and fewer support vectors remain.
  • Set Separation to 4 and C to 1000. Is there any slack left?
    AnswerNo: the classes separate, every ξi = 0, and the fit is the hard margin. A large C approaches the hard margin; with overlap the hard margin does not exist.

1. w·x + b = 0 is a line

In 2-d, w·x + b = w₀x₀ + w₁x₁ + b = 0 solves to

x₁ = −w₀w₁ x₀ − bw₁

a line with slope −w₀ / w₁ (the green triangle), crossing the x₁ axis at −b / w₁. Drag the line to change b.

2. w is orthogonal to the line

Take any two points xA, xB on the line. Both satisfy w·x + b = 0, so

(xA − xB)·w = −b + b = 0

w is orthogonal to every vector along the line (the faint copy of w). This is lesson 15's “∇g is orthogonal to its level set”, with g(x) = w·x + b and ∇g = w.

3. Assume ‖w‖ = 1

Without loss of generality, let's scale w so that ‖w‖ = 1 (the dashed unit circle). b has to scale with it so the equation still describes the same line: for any k > 0, (kw)·x + kb = 0 holds at exactly the same points as w·x + b = 0. Slide ‖w‖: w and b change, the line does not.

4. The point x = −bw is on the line w·x + b = 0

With ‖w‖ = 1,

w·(−bw) + b = −b‖w‖2 + b = 0

so x = −bw is on the line, where the w axis meets it at a right angle (step 2). It is the line's closest point to the origin, at distance |b|.

5. The margin of a point on the w axis

The point x = tw lies on the w axis, which crosses the line at −bw at a right angle. So its distance to the line is

‖tw + bw‖ = |t + b| ‖w‖ = |t + b|

Keep the sign: the margin t + b is positive on the side w points to. Drag tw.

6. The margin of any point

Project x onto the w axis: the foot is cw with

c = w·xw·w = w·x ⇒ margin = w·x + b

Sliding x parallel to the line keeps its distance, so x and cw have the same margin: step 5 with t = c. The two green segments match. For any length of w, the margin is (w·x + b) / ‖w‖.
